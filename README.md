# Coffee Delivery ☕

![Coffee Delivery](https://via.placeholder.com/1000x400.png?text=Coffee+Delivery)

## Sobre o projeto

O **Coffee Delivery** é um site desenvolvido para simular um sistema de delivery de cafés, ideal para aprendizado e demonstração de habilidades em desenvolvimento frontend. Com uma interface moderna e responsiva, o site permite que os usuários selecionem cafés, personalizem pedidos e finalizem a compra.

## Tecnologias utilizadas 🚀

- **[React](https://reactjs.org/):** Biblioteca para construção de interfaces de usuário.
- **[TypeScript](https://www.typescriptlang.org/):** Superconjunto do JavaScript para tipagem estática.
- **[Vite](https://vitejs.dev/):** Ferramenta de build rápida e moderna.
- **[Styled-components](https://styled-components.com/):** Para estilização baseada em componentes.
- **[Phosphor Icons](https://phosphoricons.com/):** Ícones para a interface do usuário.

## Funcionalidades

- 🛒 **Seleção de cafés**: Escolha entre diversas opções de cafés disponíveis.
- ➕➖ **Controle de quantidade**: Ajuste a quantidade de cada café no pedido.
- 💳 **Finalização do pedido**: Simulação de checkout com detalhes do pedido.
- 📱 **Responsividade**: Design otimizado para dispositivos móveis e desktop.

## Como executar o projeto localmente 💻

1. Clone o repositório:
gh repo clone danielpvpao/Coffee-Delivery

cd coffe-delivery
Instale as dependências:

npm install

Inicie o servidor de desenvolvimento:
npm run dev
